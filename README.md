# WatchPath AI

WatchPath AI is a legal OTT/movie availability and cost-optimization web app.

## Project Structure

This project is a monorepo containing:
- `apps/web`: Next.js frontend
- `apps/api`: Node.js Fastify API backend

## Environment Setup

Copy `.env.example` to `.env` in the root and fill in the required API keys.

## Running locally

```bash
npm install
npm run dev
```
